## Project Description

This repository contains three Web Development Lab experiments developed using HTML and CSS.

### Experiment 28: User Registration and Login Interface

**Description:**

Designed a user registration and login interface with different forms.

**Features:**
- User Registration Form
- Login Form
- Forgot Password
- Profile Setup
- Input Validation
- Password Fields

**Technologies Used:** HTML, CSS

### Experiment 29: Project and Task Management Dashboard

**Description:**

Created a project management dashboard to manage projects, tasks and team members.

**Features:**
- Project Summary
- Task Cards
- Team Members
- Task Priorities
- Deadlines
- Progress Indicators
- Kanban Board (To Do, In Progress, Completed)

**Technologies Used:** HTML, CSS, Flexbox and Grid

### Experiment 30: Bus and Train Ticket Booking Interface

**Description:**

Designed a travel booking website for bus and train ticket reservations.

**Features:**
- Source and Destination Fields
- Travel Date Selection
- Passenger Details
- Available Bus and Train Services
- Fare Information
- Seat Selection Layout
- Booking Form

**Technologies Used:** HTML, CSS, Forms and Tables

## Software Requirements

- Visual Studio Code
- HTML
- CSS
- Web Browser
- Live Server Extension

## How to Run the Projects

1. Open Visual Studio Code.
2. Open the project folder.
3. Select the required HTML file.
4. Run the file using Live Server.
5. View the output in your web browser.

## Conclusion

These three experiments helped in understanding HTML forms, CSS styling, Flexbox, Grid layouts, tables and responsive web design.
